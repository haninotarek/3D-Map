# خريطة الكلية 3D

خريطة ثلاثية الأبعاد تفاعلية لمبنيي الكلية (هندسي 1 و 2) — Three.js + Vite.

```bash
npm install
npm run dev      # http://localhost:5180
npm run build    # ينتج مجلد dist
```

## اللي موجود
- الحرم من فوق على صورة القمر الصناعي (`public/campus.jpg`) + المبنيين مجسّم 3D (واجهة، أعمدة المدخل، سطح).
- اضغط على مبنى ← يدخل جواه: 4 أدوار (أرضي + 3)، غرف ملوّنة بالنوع، لوكرز الممرات، سلالم، أثاث القاعات، وأبعاد كل غرفة.
- بحث بالمادة / الدكتور / القاعة + فلتر الفرقة واليوم ← «وديني» ← مسار + خطوات بالعربي.
- «جولة المشي»: كاميرا بمنظور شخص من البوابة لحد باب القاعة، بما فيها السلم.
- استيراد الجداول الحقيقية من زر «الجداول» (CSV/JSON).

## ⚠️ لازم تظبّطه بقياساتكم الحقيقية
| الملف | يتعدّل فيه إيه |
|---|---|
| `src/config.js` | مكان المبنيين على الخريطة، مقياس الصورة، **مكان البوابة**، `SWAP` لو المبنى 1 هو اللي على اليمين، عدد الأدوار |
| `src/layout.js` | `TEMPLATES`: نوع كل غرفة في كل دور (LH قاعة، CR فصل، LAB معمل، DR رسم، OFF مكتب، ADM إدارة، WC)، وأبعاد الجناح/الممر |
| `src/route.js` | نقط الطريق الخارجي من البوابة (`o1..o6`) |
| `src/schedule.js` | الجداول التجريبية — استبدلها أو استورد ملفكم |

الأبعاد الحالية (54×60 م للمبنى، جناح 20 م، ممر 3.6 م، ارتفاع الدور 4.2 م) تقديرية من صورة القمر الصناعي.

## صيغة ملف الجداول (CSV)
```
code,name_ar,name_en,year,instructor,day,start,end,kind,room,group
CS101,أساسيات البرمجة,Programming Fundamentals,1,د. أحمد,السبت,09:00,10:30,lecture,B1-LH1,
```
`room` = كود الغرفة (`B2-LH3` = مبنى 2 قاعة محاضرات 3) — قائمة الأكواد جوه نافذة الاستيراد.
